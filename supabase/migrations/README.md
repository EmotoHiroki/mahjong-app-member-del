# 会員削除機能の適用

既存環境では Supabase の SQL Editor で
`20261104000000_allow_admin_member_delete.sql` の内容を実行してから、
フロントエンドをデプロイしてください。既存環境で
`frontend/supabase_schema.sql` 全体を再実行する必要はありません。
新規環境向けのスキーマにも同じポリシーを追加しています。

削除は管理者限定です。既存の外部キーにより、対象会員の対戦結果と
ポイント履歴も削除され、プロフィールの会員紐付けは解除されます。
他の会員の結果と対戦レコード、ログインアカウントは残ります。

## 検証環境での確認

- 管理者で仮会員・正式会員それぞれの削除確認画面を開き、キャンセルすると会員が残る。
- 削除確定後、一覧と人数が更新され、再読み込み後も削除された会員が表示されない。
- 対象会員の対戦結果・ポイント履歴が削除され、他会員の結果・履歴が残る。
- 正式会員の `profiles.member_id` が NULL になり、Auth ユーザーは残る。
- スタッフ・一般会員には削除ボタンが表示されず、API を直接呼んでも会員を削除できない。
- 削除用ポリシー未適用時や通信失敗時、成功表示にならず、エラーと再試行・キャンセル操作が表示される。

本番の会員データではなく、専用の検証データで確認してください。
